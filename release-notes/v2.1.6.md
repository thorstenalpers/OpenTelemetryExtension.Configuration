# v2.1.6

_Released: 2026-10-31_

## Changed
- Updated the bundled OpenTelemetry packages (`Exporter.OpenTelemetryProtocol`,
  `Extensions.Hosting`, `Instrumentation.Http`, `Instrumentation.AspNetCore` and
  `Instrumentation.Runtime`) to 1.20.1. No public API or runtime behavior change.
- Updated the sample and test project dependencies (EF Core, ASP.NET Core OpenAPI,
  `Microsoft.Extensions.Hosting`, HTTP resilience, service discovery, NLog,
  Swashbuckle, `Microsoft.Data.SqlClient`, `OpenTelemetry.Instrumentation.SqlClient`,
  test SDK and xUnit runner). These are not part of the shipped package.

## Fixed
- Pinned `System.Security.Cryptography.Pkcs` to 10.0.14 in the sample Web API and
  the integration tests to override a vulnerable transitive version
  (GHSA-2fmv-rv2c-59x7, GHSA-846f-f764-76mx) pulled in by `Microsoft.Data.SqlClient`.
  The shipped package was not affected.
